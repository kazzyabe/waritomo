# IP Boundary

## Positioning

This app is not a Walica clone or migration. It is a new LINE mini app in the
general split-expense category.

## Do Not Use

- Walica name, logo, icon, colors, copy, help text, screenshots, or OGP assets.
- Walica source code, bundled JavaScript, CSS, API implementation, or database design.
- Walica-specific route names, UI composition, button labels, or interaction sequences when they are not generic.
- Any scraped or reverse-engineered private behavior as an implementation source.

## Safe To Use

- General accounting concepts:
  - members
  - groups
  - expenses
  - payers
  - debtors
  - settlement suggestions
  - currency conversion
- Public LINE and Google Cloud documentation.
- Original UX, API, schema, copy, and assets created for this project.

## Original Product Principles

- Design around LINE-native collaboration, not web URL sharing as the primary flow.
- Treat each participant as a LINE user who can claim a member slot.
- Make settlement status trackable, not only calculable.
- Keep the UI compact and operational, optimized for repeated use during a trip.
